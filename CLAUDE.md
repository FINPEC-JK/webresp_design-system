# Notas persistentes (FINPEC)
- Temas: apenas Claro e Escuro (sem "Sistema").
- Configurações (cadastros, criação de acessos, perfis etc.): sempre como subitens dentro de um item do menu lateral esquerdo (ex.: "Configurações"), nunca no rodapé.
- Item que aglutina vários subitens é sempre expansível/retrátil (Sidebar: `children`).
- Rodapé do menu lateral: toggle claro/escuro + data/hora → avatar com iniciais, nome, perfil, Sair → código do release (só a versão).
- Todas as telas de login seguem a estrutura de login documentada no readme.md ("Tela de Login"): painel escuro à esquerda + imagem full-bleed, login via SSO, Usuário+Senha ou ambos, aba vertical "Release notes" expansível.
